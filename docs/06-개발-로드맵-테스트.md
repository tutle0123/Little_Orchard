# 06. 단계별 개발·테스트 체크리스트

'파일 만들기'보다 **작동하는 결과를 작은 단계로 쌓는 것**이 중요합니다. 단계별로 커밋을 남깁니다.

## M0 — 환경과 저장소

- [ ] GitHub 저장소에 모든 파일 업로드 (숨김 `.github` 포함)
- [ ] `npm install` 및 `package-lock.json` 커밋
- [ ] `npm run test`, `npm run build` 정상 종료
- [ ] 기술 데모 이동·씬 전환 확인
- [ ] 첫 태그 `v0.0.1` 또는 첫 정상 커밋 기록

## M1 — 작물 하나가 제대로 동작

- [ ] 사과나무 접근 → 상호작용 → 아이템 추가
- [ ] 수확 뒤 나무에서 열매 시각적으로 사라짐
- [ ] 재성장 시간 후 다시 수확 가능
- [ ] 중복 상호작용을 해도 아이템 복제 버그 없음
- [ ] 과일 수량 저장 → 새로고침해도 유지

## M2 — 과일 세 종류와 가게

- [ ] 사과·배·감 각각 규칙대로 수확
- [ ] 과수원 ↔ 청과점 이동
- [ ] 진열대에 재고 배치 → 가방 재고가 줄어듦
- [ ] 손님 입장→진열대→구매→퇴장
- [ ] 코인 증가·진열대 감소 정확함
- [ ] 과일 없는 상태에서 음수 재고/무한 코인 버그 없음

## M3 — 작은 게임으로서 완성

- [ ] 기본 픽셀아트(인물 4방향, 3종 나무, 가게, UI) 교체
- [ ] 간단한 이펙트·효과음·튜토리얼
- [ ] 기기별 화면 크기·입력 테스트
- [ ] 플레이 후 재접속해도 진행 유지
- [ ] 버전 태그/릴리스, 변경 기록 작성

## M4 — 재미와 확장 검증

- [ ] 최소 10분 플레이하며 지루하거나 불편한 지점 기록
- [ ] 새 과일을 추가할 때 데이터·그림·테스트만으로 가능한지 검증
- [ ] 손님 구매 주기/가격/재성장 속도 밸런스 조정
- [ ] 플레이어 피드백으로 '재미'를 확인하고 추가 콘텐츠 결정

## 기기별 필수 체크

| 테스트 | Windows PC Chrome | Android Chrome | iPhone Safari |
|---|:---:|:---:|:---:|
| 최초 진입 / 화면이 잘리지 않음 | ☐ | ☐ | ☐ |
| 4방향 이동 / 이동 중 멈춤 | ☐ | ☐ | ☐ |
| 수확/가게 이동/진열/판매 | ☐ | ☐ | ☐ |
| 터치 버튼 누름/손 뗌 (모바일) | — | ☐ | ☐ |
| 가로 / 세로 회전 후 UI 위치 | ☐ | ☐ | ☐ |
| 새로고침/브라우저 종료 후 저장 | ☐ | ☐ | ☐ |
| 10분 플레이 / 성능·발열 | ☐ | ☐ | ☐ |
| 오류 메시지/스크롤/더블 탭 확대 | ☐ | ☐ | ☐ |

> 결과를 확인하기 전까지 '테스트 통과'로 기록하지 않습니다. PC에서만 확인하고 모바일 통과라고 표시하면 안 됩니다.
