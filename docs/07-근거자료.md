# 07. 공식 문서·선택 근거 (확인일 2026-11-08)

**프로젝트 설계의 기준일**: 2026년 11월 8일. 배포 설정/라이브러리 새 버전은 바뀔 수 있으므로 개발 재개 시 버전 확인.

## Phaser

- Phaser npm 설치 및 공식 템플릿: https://docs.phaser.io/phaser/getting-started/installation
- Phaser 3.90.0 공식 릴리스: https://phaser.io/download/release/v3.90.0
- Phaser GitHub 릴리스(현재 4.x도 존재): https://github.com/phaserjs/phaser/releases
- **결정**: AI 생성 코드의 API 불일치 가능성을 줄이고 기존 3.x 문서·예제를 활용하기 위해 **Phaser 3.90.0에 고정**. 향후 4.x 마이그레이션은 별도 작업.

## Vite

- 시작·Node 버전: https://vite.dev/guide/
- GitHub Pages 정적 배포·`base` 설정: https://vite.dev/guide/static-deploy
- Vite 8 및 Node.js 최소 지원 버전: https://vite.dev/blog/announcing-vite8
- **결정**: Vite 8.0.0으로 빌드하되 Actions에서 `VITE_BASE`를 `/${저장소이름}/`으로 전달. GitHub Pages `dist/` 게시.

## GitHub

- Pages 게시 소스(브랜치 vs Actions): https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
- Pages 사이트 생성/게시: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
- 브랜치 보호: https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches
- **결정**: Vite는 빌드가 필요하므로 Pages Source를 `GitHub Actions`로. `main`만 자동 배포.

## 저장과 앱 전환

- 브라우저 저장은 동일 기기·동일 origin 안에서만 기본적으로 유지됩니다. 브라우저 데이터 정리/설정에 따른 손실 가능성 때문에 중요한 저장 데이터는 추후 내보내기를 검토합니다.
- 현재 **PWA 오프라인 캐시 기능을 제공하지 않습니다.** GitHub Pages 접속에는 보통 인터넷 연결이 필요합니다.
- 향후 안드로이드 앱화는 Capacitor(https://capacitorjs.com/docs) 같은 웹기반 패키징 방식을 검토. 단, 자동 변환 완료를 보장하는 것은 아님.

## 검증 한계

작성 환경에서 npm 레지스트리에 연결할 수 없어 Node 패키지 설치, 정식 Phaser/Vite 실행, GitHub Pages 실제 배포, 모바일 실기기 테스트는 수행하지 못했습니다. 제공된 자동 테스트는 순수 JavaScript 로직의 일부만 확인합니다. 본격 개발 시 `START-CODEX.md` 순서대로 검증해야 합니다.
