# 혹시 필요할 때 보는 예비 에셋 목록

이 문서는 [제작 체크리스트](10-직접-만들어올-에셋-체크리스트.md)의 보충 자료다. 모두 지금 만들라는 뜻도, 해당 기능을 추가하기로 결정했다는 뜻도 아니다. 범위는 기존6과일·과수원·청과점 중심으로 유지한다. 그림체 기준은 승인된 한 알 블루베리다.

**지금 준비하면 유용**: 기본 기능에서 재사용 가능성이 높음. **규칙 결정 후**: 기능을 정해야 필요한 상태가 확정됨. **나중 선택**: 없어도 기본 게임을 완성할 수 있음.

## 1. 여섯 작물의 추가 상태

각각 사과/배/귤/복숭아/블루베리/감에 공통으로 적용할 수 있는 후보다.

### 지금 준비하면 유용
- [ ] 열매 없는 식물 몸체.
- [ ] 익은 작은 열매만 따로: 나무/관목에 붙이는 레이어.
- [ ] 식물 기준점/가지와 열매 위치를 표시한 설명용 그림.
- [ ] 수관/줄기를 분리한 버전: 플레이어 가림 처리용. 원본 레이어가 있으면 추출 가능.
- [ ] 작은/큰 접지 그림자: 같은 그림자를 여러 식물에 재사용 가능.

### 규칙 결정 후
- [ ] 묘목/어린 식물/성숙 식물.
- [ ] 꽃봉오리/꽃 핀 상태.
- [ ] 갓 맺힌 작은 열매/덜 익음/거의 익음/완숙.
- [ ] 수확 후 몇 개만 남은 상태: 열매 레이어로 처리 가능.
- [ ] 수확 중 살짝 기울어진 모습: 코드 흔들림으로 대체 가능.
- [ ] 심기 구덩이/흙 덮인 상태/지지대.
- [ ] 가지치기 후/전정 도구.
- [ ] 비료·멀칭 표시, 잡초 있음/없음.
- [ ] 잎이 살짝 처진 건조 상태/정상 회복 상태.

### 나중 선택
- [ ] 봄·여름·가을 잎 색, 겨울 가지/눈 덮임.
- [ ] 낙엽/꽃잎이 떨어지는 소량 입자.
- [ ] 병해/벌레/회복 표시.
- [ ] 죽은 나무/그루터기/쓰러진 나무: 해당 규칙을 도입할 때만.
- [ ] 다른 크기의 성목/무성한 장식용 변형.

성장×열매×수분×계절의 모든 조합을 완성 그림으로 각각 만들지 않는다. 몸체·열매·뿌리 주변 흙·작은 표시를 나누면 중복 제작량이 크게 줄어든다.

## 2. 과일 자체의 추가 모습

### 지금 준비하면 유용
- [ ] 가방 아이콘과 같은 과일의 작은 월드 표시.
- [ ] 떨어지거나 획득할 때 쓰는 단순 실루엣: 기존 아이콘 재사용 가능.
- [ ] 진열용 단일 과일/살짝 돌아간 과일.
- [ ] 바구니/상자에 담긴 과일 묶음.

### 규칙 결정 후
- [ ] 소량/충분/가득한 과일 배치.
- [ ] 품질 등급 표시용 리본·별·스티커: 과일 본체를 다시 그릴 필요 없음.
- [ ] 흠집/멍/과숙/상한 과일: 신선도 시스템 도입 시.
- [ ] 선물용 과일 묶음/포장망/포장된 상자.
- [ ] 씨앗/묘목 상품 아이콘: 재배 방식에 맞춰 결정.

### 나중 선택
- [ ] 반으로 자른 단면/조각: 손님 샘플이나 판매 방식이 실제 필요할 때.
- [ ] 큰 과일/작은 과일 변형, 특별 수확 표시.

아이템 한 단위의 블루베리는 한 알이다. 진열/포장/식물 위에는 여러 알 표현을 사용할 수 있다. 과일에 숫자·등급 문자를 직접 그리지 않는다.

## 3. 청과점 선반·상자·가구

### 지금 준비하면 유용
- [ ] 선반 좌/중/우 연결 조각, 기둥/받침, 상단/중단/하단 칸.
- [ ] 낮은 선반/높은 선반, 낮은 진열함.
- [ ] 얕은 과일 트레이/작은 바구니/깊은 보관 상자.
- [ ] 빈 상자와 그 위에 얹을 과일 레이어.
- [ ] 영업용 간판의 빈 판, 상품 가격표의 빈 판.
- [ ] 계산대의 앞쪽 가림층: 뒤에 선 캐릭터의 하반신 가림.
- [ ] 문·창문·출입구 바닥 매트.
- [ ] 손님용 쇼핑 바구니, 종이봉투의 빈/담긴 모습.

### 규칙 결정 후
- [ ] 품절/재입고/예약/할인/추천 표시의 빈 배경판.
- [ ] 판매대 저울, 포장대, 포장지/끈/리본.
- [ ] 창고 선반, 열린/닫힌 보관함.
- [ ] 손수레/운반 상자, 손에 드는 과일 바구니.
- [ ] 개선 전/후 선반, 상점 확장 구역.
- [ ] 영업 중/준비 중/마감 안내판: 글자는 코드로.
- [ ] 냉장 진열대/저온 보관함: 신선도 규칙 도입 시.
- [ ] 넘어지거나 흩어진 상품/정리된 상태: 정리 시스템 도입 시.

### 나중 선택
- [ ] 벽등, 시계, 화분, 작은 액자, 포스터용 빈 종이.
- [ ] 의자/작은 테이블/쓰레기통/빗자루·쓰레받기.
- [ ] 축제/계절 장식.
- [ ] 자유 배치 기능을 만들 경우 측면/뒷면 가구와 회전 방향.

현재는 벽면 선반이 기본이다. 매장 자유 회전이나 중앙 매대를 도입하지 않으면 모든 가구의 앞뒤좌우4방향은 필요하지 않다.

## 4. 과수원·건물 주변

### 지금 준비하면 유용
- [ ] 잔디·흙길·마른흙·젖은흙의 작은 패턴 변형.
- [ ] 길 경계/모서리/갈림길/끝부분: 반복 타일 방식 선택 시.
- [ ] 울타리 연결부/끝기둥/열린 문/닫힌 문.
- [ ] 건물 문/지붕 전경 가림층/창문/간판의 빈 판.
- [ ] 바닥과 건물/나무의 접지 그림자.
- [ ] 낮은 풀·꽃·돌의 몇 가지 변형.

### 규칙 결정 후
- [ ] 새 재배 구역 표식, 잠긴 출입구, 구역 확장 표지판.
- [ ] 물통/물탱크/수도꼭지/우물/급수대 중 선택한 급수 방식.
- [ ] 호스/스프링클러/물뿌리개: 자동 급수 도입 시.
- [ ] 도구걸이/작업대/묘목 놓는 곳/비료 포대.
- [ ] 운반 카트/쌓인 상자/작은 수확물 적재 장소.

### 나중 선택
- [ ] 벤치, 우편함, 화단, 작은 표지판.
- [ ] 얕은 연못/물가/돌길/작은 다리: 새 이동 경로가 필요할 때.
- [ ] 나뭇잎/꽃/잡초/흙 발자국 등 작은 장식.
- [ ] 먼 배경의 수목·언덕·하늘.
- [ ] 밤의 창문 빛/등불, 비 온 뒤 웅덩이/물결, 눈 쌓임.

## 5. 플레이어 동작과 외형

### 지금 준비하면 유용
- [ ] 앞·뒤·좌·우 정지와 걷기.
- [ ] 인물 비율표/방향별 기준 그림/색상표.
- [ ] 고정된 발 위치와 발밑 그림자.
- [ ] 손 뻗기/수확/선반 보충 동작의 재사용 가능한 기준.
- [ ] 물건을 들지 않은 손/빈손 버전.

### 규칙 결정 후
- [ ] 물주기/묘목 심기/땅 파기/비료 주기/가지치기.
- [ ] 높이 있는 나무에서 따기/낮은 관목에서 따기.
- [ ] 한 손 과일 들기/양손 상자 들기/바구니 운반.
- [ ] 도구 바꾸기/상자 열기/문 열기.
- [ ] 계산대 응대/상품 포장/상품 건네기/돈 받기.
- [ ] 빗자루질/물건 줍기: 정리 시스템 도입 시.

### 나중 선택
- [ ] 대기 중 눈 깜박임/숨쉬기, 달리기, 앉기/쉬기.
- [ ] 기쁨/놀람/고민/아쉬움 표정 또는 말풍선.
- [ ] 모자·앞치마·가방·장갑 등 최소 소품.
- [ ] 비옷/우산/겨울옷: 날씨/계절 시스템 도입 시.

같은 얼굴·머리·옷·몸 비율을 고정하고 프레임을 만든다. 장식에 비대칭이 있으면 좌우 반전 가능 여부를 확인한다. 도구/들고 있는 물체를 분리하면 동작별 소품을 모두 새로 그리지 않아도 된다.

## 6. 손님 동작과 반응

### 지금 준비하면 유용
- [ ] 첫 손님 앞·뒤·좌·우 정지/걷기.
- [ ] 상품 관심 표시/구매 완료 표시.
- [ ] 빈손/봉투 들고 있는 상태.
- [ ] 순서 대기/선반 앞에 서기: 기존 정지 동작 재사용.

### 규칙 결정 후
- [ ] 원하는 과일 말풍선: 과일 아이콘 재사용.
- [ ] 상품 집기/계산대 전달/봉투 받기.
- [ ] 기다림/만족/품절 실망 표시.
- [ ] 추가 외형1~2종, 다른 옷/헤어 색.

### 나중 선택
- [ ] 인사/작은 대화, 단골 표시, 주문 전달 표시.
- [ ] 어린이/노인 등 체형 변형: 크기와 이동·상호작용 위치도 함께 검수.

입장/이동/대기/구매/퇴장 로직만으로 손님이 살아 움직일 수 있다. 각각에 전용 애니메이션을 전부 만들 필요는 없다.

## 7. UI와 안내 상태

### 지금 준비하면 유용
- [ ] 가방/코인/과일6종/물뿌리개 아이콘.
- [ ] 공통 패널·버튼·아이템 칸·선택 테두리.
- [ ] 버튼 기본/누름/비활성/선택: 코드 색상으로도 구현 가능.
- [ ] 성장 중/수확 가능/가방 비었음/재고 없음 안내.
- [ ] 뒤로/닫기/설정/음소거/소리 켜짐.
- [ ] 터치 이동/상호작용/물주기 표시.
- [ ] 입력 대상을 알아보기 위한 작은 마커/테두리.

### 규칙 결정 후
- [ ] 가방 가득참/잘못된 위치/성장 대기/물 충분함 표시.
- [ ] 저장 중/저장 완료/저장 실패/불러오기/초기화 확인.
- [ ] 도움말/튜토리얼/새 기능 알림/품절 표시.
- [ ] 물 잔량/수분/성장 진행/업그레이드·잠금 표시.
- [ ] 상품 선택/진열 보충/보유 수량 선택/확인·취소 창.

### 나중 선택
- [ ] 상점 이름판/타이틀/시작 화면/크레딧 배경.
- [ ] 목표 달성/수확 기록/판매 기록/도감의 빈 칸.
- [ ] 시간/달력/계절 아이콘: 시스템 채택 시.

한글·숫자·가격·시간·수량·설명은 코드에서 표시. 모든 UI 상태를 PNG로 만들 필요는 없다. 접근성은 색에만 의존하지 않고 모양/글자도 함께 사용한다.

## 8. 작은 효과·환경 변화

### 지금 준비하면 유용
- [ ] 수확 반짝임/획득 강조/판매 반짝임.
- [ ] 물방울/물줄기/흙에 닿는 물 튀김.
- [ ] 작은 먼지/발자국/잎 흔들림용 조각.
- [ ] 상품 보충/구매 강조 테두리.

### 규칙 결정 후
- [ ] 성장 완료 반짝임/꽃잎/낙엽.
- [ ] 비/눈 입자/바람에 날리는 잎, 물가 잔물결.
- [ ] 낮/저녁/밤 조명 오버레이, 창문 빛, 실내등 빛.

### 나중 선택
- [ ] 작은 나비·벌·새: 장식으로만 필요할 때.
- [ ] 특별 수확/목표 달성 효과.

튀기기·흔들기·기울이기·날아가기·커졌다 줄어들기는 대부분 기존 그림을 움직이는 코드로 가능하다. 이 움직임마다 별도 이미지를 그릴 필요 없다.

## 9. 앱/웹 화면용 예비 이미지

- [ ] 웹사이트 파비콘/앱 아이콘의 단순한 심벌.
- [ ] 시작/로딩 배경, 글자를 올릴 여백 있는 제목 그림.
- [ ] 게임 소개용 대표 그림1장.
- [ ] 작은 썸네일/공유 카드: 대표 그림을 잘라 쓸 수 있는 구도.
- [ ] 추후 설치형앱 전환 시 아이콘 전경/배경과 스플래시 규격.

실제 게임 화면은 구현 후 캡처한다. 소개용 그림을 실제 플레이 캡처처럼 표시하지 않는다. 앱스토어·결제·광고 에셋은 현재 범위에서 준비하지 않는다.

## 10. 이미지와 별도로 필요한 소리

- [ ] 버튼/확인/취소/수확/획득/진열/구매·코인/문.
- [ ] 물 따르기/물방울/발소리/잎 흔들림.
- [ ] 선택: 자연 환경음/가게 잔잔한 환경음/음악.

이 항목은 GPT 이미지 생성 대상이 아니다. 그림 제작 뒤 별도 작업으로 남겨도 된다.

## 11. 작업할 때 함께 보관하면 좋은 자료

- [ ] 각 분류의 승인 기준 이미지: 과일/식물/인물/건물/선반.
- [ ] 색상·빛 방향·윤곽·질감·비율 기준표.
- [ ] 원본 PNG/편집용 원본, 상태 이름·방향·동작 이름.

1. 빈 선반1개 + 빈 상자1개 + 과일6종 레이어로 진열 상태를 구성.
2. 나무 본체 + 열매 + 뿌리 주변 흙 + 수분 표시를 분리.
3. 인물 몸체/도구/들고 있는 물체를 분리하고 재사용.
