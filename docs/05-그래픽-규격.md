# 05. 픽셀아트 제작·리소스 규격

## 목표

일러스트에 '픽셀 필터'를 씌운 그림이 아니라 **네이티브 픽셀 그리드에 맞춰 실제로 찍은 게임용 스프라이트**를 사용합니다. 레퍼런스는 분위기를 정하기 위한 것이며 타 게임 그래픽을 그대로 복제하지 않습니다.

## 시범 규격 (진행 중 조정 가능)

- 기본 맵 타일: **16×16 논리 픽셀**
- 주인공 스프라이트: **16×24 논리 픽셀**, 4방향 × 방향당 3~4프레임부터
- 과일 아이템: **16×16 픽셀** 이내
- 나무: 대략 **32×48 픽셀**의 고유 실루엣, 수확 가능/불가능 시각 차이
- 화면 기준 캔버스: **480×270 논리 픽셀**, 화면에 맞춰 nearest-neighbor 확대
- 광원·명암·그림자 방향을 일관되게. 캐릭터 발 아래 접지 그림자
- `pixelArt: true`, `roundPixels: true`, Phaser scale FIT 설정 (코드 기반)

이 수치는 절대 규칙이 아니라 **통일감을 위한 출발점**입니다. 한 번 정식 스프라이트를 제작하기 시작하면 중간에 마구 변경하지 않는 것이 좋습니다.

## 처음 필요한 실제 리소스

- 잔디·흙길·울타리 타일 4~8개
- 캐릭터 기본 걷기 4방향 애니메이션
- 사과·배·감 아이템 각 1개
- 3종 나무: 성숙 상태(열매 있음/없음) 각 2개
- 청과점 바닥/벽/문/진열대/계산대
- 손님 1종의 걷기 애니메이션
- UI: 작은 버튼·패널·코인 심벌

처음부터 모든 가구/배경/계절을 제작하지 않습니다. 움직이는 모습과 상호작용을 먼저 확인합니다.

## 에셋 구하는 법

1. 가능하면 직접 제한된 팔레트로 스프라이트 시트 제작.
2. 유료·무료 픽셀아트 에셋팩을 구할 경우 **상업적 이용, 수정, 재배포, 출처표시** 조건 확인.
3. AI 생성 이미지는 구상·참고용으로 활용 가능하나, 실제 스프라이트의 픽셀 정렬/연속 프레임은 별도로 제작·검수.
4. 파일명은 `apple_tree_ready.png`, `apple_tree_empty.png`, `player_walk_down.png` 등 직관적으로.
5. 모든 외부 에셋 출처·제작자·사용 조건을 `assets-licenses.md` 같은 문서에 기록(실제 사용 시작 시 생성).

## 그래픽 완료 확인

- 픽셀 크기·에지 선명도 일관성
- 화면 축소·확대 시 흐려지거나 윤곽이 깨지지 않음
- 캐릭터 발과 바닥, 나무 밑동 위치 자연스러움
- 나무 상태가 멀리서도 구분됨
- 손님과 플레이어의 스케일 통일
- 휴대폰 작은 화면에서 UI의 가독성과 터치 영역 확보
