# 클라우드 검증 — 2026-11-08

원본 ZIP을 기존 체크아웃에 가져옴. 원본 코드와 기획은 유지했으며 새 게임 기능을 추가한 단계는 아님.

- Node 24.22.1, npm 11.9.0, Phaser 3.90.0, Vite 8.0.0.
- `npm install --cache /workspace/.npm-cache`, `npm run test` (4/4), `npm run build` 통과.
- Chromium 자동 확인: 키보드 이동, 사과 수확/중복 방지, 씬 이동, 진열, 손님 판매 +6코인, 새로고침 후 저장 복원 통과.
- 상호작용 검사는 테스트에서 캐릭터를 대상 가까이 배치한 뒤 키보드로 실행. 전체 경로를 걸어서 플레이한 검사는 아님.
- 1280×720, 390×844, 844×390에서 스크린샷 생성 및 가로 넘침 없음 확인. 터치/회전/Android·iOS 실기기 및 10분 재미 검증은 미완료.
- 아트는 원본의 임시 아트. 정식 픽셀아트 완성으로 간주하지 않음.
- 손상된 저장을 읽은 후 자동 저장이 원본을 덮어쓸 가능성 등 저장 보호 정책은 추가 점검 필요.
- 빌드의 500kB 초과 경고는 남음. 빌드 오류는 아님.

## 실행

기존 `/workspace/Little_Orchard` 체크아웃 사용. 별도 worktree 불필요.
Node >=22.12 필요. `npm ci --cache /workspace/.npm-cache`, `npm run check`, `npm run dev`.

## 배포 및 검토

`feature/first-playable`에 원본과 잠금 파일을 보관. main 자동 병합/공개 배포는 하지 않음.
CI는 main push 또는 main 대상 PR에서 실행. Pages 워크플로도 포함되어 있지만 실제 Actions 실행과 Pages 활성화는 미확인.
원격이 처음 비어 있었으므로 main이 아직 없을 수 있음. GitHub의 브랜치 목록에서 확인 후 검토한 커밋으로 main을 생성하고 Settings → Branches에서 기본 브랜치 지정.
Settings → Pages → Build and deployment → Source: GitHub Actions.
Actions → Publish game to GitHub Pages의 성공 여부 확인 후 Settings → Pages의 실제 URL 확인.
Codex 환경 설정의 설치/시작 지침을 검토·저장 후 Publish. 이 문서는 게시 완료를 의미하지 않음.
