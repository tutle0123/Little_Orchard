## 추천 기술

- **Phaser 3.90.0**: 웹 기반 2D 게임 라이브러리. 최신 주 버전 4와의 차이로 인한 호환성 변수를 줄이기 위해 **3.90.0 고정**.
- **Vite**: 로컬 개발 서버·웹 빌드 도구. 프로젝트에서 8.0.0 고정(설치 후 업데이트는 별도 검증).
- **JavaScript(ES 모듈)**: 작고 단순하게 시작. 도메인 로직·씬·UI를 파일별로 분리.
- **Git + GitHub**: 코드 이력·복구·태그 관리.
- **GitHub Actions + Pages**: `main` 업데이트 시 (Pages 활성화 후) 웹 버전 자동 빌드·공개.
- **localStorage**: 게임 저장. **기기별 별도 저장**이며 삭제될 수 있으므로 장기적으로 내보내기/가져오기 고려.

## 처음 실행하기 (Node.js 설치 필요)

```bash
npm install
npm run dev
```

명령창에 나오는 로컬 주소를 PC에서 열어 게임 기술 데모를 확인합니다. **`npm install` 후 생성되는 `package-lock.json`도 Git에 커밋**해 주세요. 잠금 파일이 있으면 자동화에서 `npm ci`를 사용합니다.

```bash
npm run test
npm run build
```

> 이 ZIP은 패키지를 포함하지 않습니다. 본 환경에서 npm 레지스트리 접속이 불가해 실제 Phaser/Vite 빌드 및 모바일 화면 실행까지는 검증하지 못했습니다. JavaScript 문법·순수 로직 테스트는 로컬에서 별도로 검사합니다. 첫 단계에서 Codex가 `npm install`, `npm run test`, `npm run build`, PC/모바일 화면 확인을 수행해야 합니다.

## GitHub Pages로 게시하기

- GitHub에 저장소를 만들고 이 ZIP 내부 **파일과 숨김 폴더 `.github`를 그대로 업로드**합니다.
- 저장소 **Settings → Pages → Build and deployment → Source: GitHub Actions**를 선택합니다.
- 기본 브랜치를 `main`으로 유지합니다. 푸시되면 `.github/workflows/deploy.yml`이 빌드하여 `dist/`를 게시합니다.
- 주소 예: `https://<아이디>.github.io/<저장소이름>/`
- 컴퓨터를 끄고 휴대폰에서 링크를 열어도 서버에 올라간 게임은 접속 가능합니다. **인터넷은 필요**하며 PC에서만 돌리는 `npm run dev` 서버는 PC를 끄면 접속할 수 없습니다.
- Vite `base` 경로는 Actions에서 **저장소 이름 기반으로 자동 설정**합니다. 사용자가 직접 `/repo/`를 고치지 않아도 되도록 구성했습니다. 단, `<아이디>.github.io`라는 특수 루트 저장소에 배포할 때는 `base: /`로 별도 조정하세요.
