# 그림체 기준 — 밝고 통통한 캐주얼 일러스트

2026-11-09 사용자 피드백으로 갱신. 이전 18장 묶음은 그림체가 달라지고 나무 질감이 과해 최종 채택 보류다. 사용자가 새로 제시한 선명하고 매끈한 블루베리 이미지의 '뿅뿅뿅' 느낌이 기준이다.

## 고정할 특징

- 잎: 선명한 연두/초록, 넓고 통통한 형태, 간결한 잎맥 한 줄과 작고 부드러운 광택.
- 열매: 둥글고 탱글한 입체감, 선명한 파랑/보라, 둥근 꽃모양 꼭지와 작은 밝은 하이라이트.
- 줄기: 따뜻한 주황빛 갈색, 매끈한 표면과 간결한 분기. 꼬인 줄기·손가락 같은 뿌리·나무껍질 비늘 무늬를 넣지 않음.
- 명암: 부드럽고 간결하게, 밝은 캐주얼 게임 일러스트. 무거운 사실적 텍스처·붓질·지나치게 짙은 갈색 테두리를 피함.
- 블루베리: 다른 과수보다 낮고 넓은 관목. 그림체와 식물의 실제 배치 크기는 따로 검수.
- 고해상도 일러스트이며 네이티브 픽셀 격자 에셋이라고 설명하지 않음.

## 기준 파일과 검수

새 스타일의 첫 검토 묶음은 `generated/v3/`의 블루베리 수확 전·후·아이콘3종이다. 사용자가 승인한 것은 그림체 방향이고 이3개 개별 파일의 최종 승인은 아직 받지 않았다. `generated/v3/blueberry-bush-ripe.png`를 다음 작업의 일관성 비교 후보로 쓴다. 이전 사과 등 여러 스타일을 번갈아 주 기준으로 사용하지 않는다.

생성할 때마다 기준 이미지와 결과를 나란히 확인한다. 광택/채도/윤곽/질감/잎 밀도/목재 표현/시점·비율이 바뀌었으면 파일 생성 성공과 별개로 불합격 처리한다. 반복 배치의 부자연스러움도 확인하되, 사용자가 선호한 통통한 과일 송이를 임의로 모두 제거하지 않는다.

투명알파는 실제 밝은색/잔디색 합성으로 확인한다. 원시 프리뷰에 남은 투명영역 RGB를 불투명 배경으로 오인하지 않는다. 크기·밑동 정렬·게임상태 전환·작은 화면 가독성까지 확인해야 실제 게임 적용 완료다. v3의 기술검사와 실제 게임 검수를 구분해 보고한다.

원본/이전 버전은 보존하고 버전 폴더로 작업한다. 이미지 생성·수정은 이미지 도구로 하고, 비교 뷰어/해시/메타데이터는 코드로 관리한다. 게임과 공개 배포는 별도 작업이다.
