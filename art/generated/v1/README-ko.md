# GPT 생성 에셋 1차 묶음

사과·배·귤·복숭아·블루베리·감의 수확 전 식물, 수확 후 식물, 과일 아이콘: 18개 제작 항목. 생성 시도는 20장.

- 18개: 시각 비교용 후보. 실제 게임 적용/정렬/폰 실기기 검수 전.
- 블루베리: 원시 미리보기의 초록빛을 처음에는 번짐으로 판단해 2회 추가 시도함. 실제 RGBA 값과 브라우저 흰색/잔디색 합성에서 거의 투명한 영역의 RGB임을 확인해 보류 해제. 원본 pair를 선택하고 추가 시도2개는 대안으로 보존.
- 전부 RGBA PNG이며 파일 손상/해시/알파를 검사함. 알파가 있다고 배경 정리가 완벽하다는 뜻은 아님.
- 사과·배·복숭아 쌍의 캔버스 크기는 동일. 귤은 폭 1px, 감은 높이 1px 차이. 같은 크기 쌍도 그림 내부의 잎과 가지가 완전히 일치하지는 않음.
- 현재 그림은 고해상도 일러스트. 네이티브 픽셀 격자 스프라이트가 아님.
- 원본은 각 generation_original 경로에 보존. 이 폴더는 복사본과 검사 기록.
- index.html은 비교용 뷰어. 실제 게임이 아니며 파일 목록을 고쳐서 이미지 자체를 편집하지 않음.
- 단독 감상 품질과 모바일 게임 축소 품질은 구분. 배경 위 경계, 밑동, 과일 수확 연출을 인게임 검수해야 함.
- 기존 게임, main, GitHub Pages는 변경/게시하지 않음.

## 다음 생성 순서

1. 원본 PNG의 알파와 실제 게임 배경에서 경계 검수를 계속 유지.
2. 상태 전환의 기준점/캔버스를 통일하고 실제 크기로 검수.
3. 승인 스타일로 실내 빈 목재 선반 → 빈 과일 상자 → 과일 진열 레이어.
4. 과수원 지형·청과점 실내 배경.
5. 인물 방향/동작.

매 단계마다 사용자가 새로 지시할 필요 없이 한 묶음의 범위를 먼저 정하고 순차 생성·검수한다. 지금 상시/예약 작업이 돌고 있는 것은 아니다.
