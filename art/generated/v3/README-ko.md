# 밝고 통통한 캐주얼 그림체 · 블루베리 3종

사용자가 제시한 새 그림체의 기준: 선명한 연두/초록 잎, 매끈한 주황빛 줄기, 둥글고 윤기나는 파란 열매, 간결한 꽃모양 꼭지, 부드러운 입체 명암. 사실적 나뭇결·붓질·짙은 갈색 테두리를 줄임.

파일은 수확 전 식물, 수확 후 식물, 과일 아이콘 3개. 고해상도 일러스트이고 네이티브 픽셀아트가 아님. 투명RGBA와PNG해시/디코딩 검증, 흰색/잔디색 브라우저 합성 확인. 두 식물 캔버스1536×1024 동일.

게임 적용, 밑동 기준점/수확전후 내부 그림의 완전 정렬, 모바일 실기기 검수는 아직 안 함. 이 결과물 자체의 사용자 최종승인 전. 이전18개 그림체는 새 기준으로 재검토 전까지 채택 보류.

index.html: 비교 뷰어. preview-white.png/preview-grass.png: 실제 투명PNG를 브라우저에 얹은 확인용 화면. 원시 미리보기 RGB와 알파 합성 결과는 구분.

## 아이콘 수정
